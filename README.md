## 🚀 What I'm Building

I'm building a collection of **production-oriented software systems and engineering projects** designed to explore real-world backend engineering, distributed systems, and full-stack product development.

My projects focus on:

- 🏗️ **Microservices Architecture** — designing independently deployable services with clear domain and data ownership.
- 🔄 **Event-Driven Systems** — Kafka, asynchronous workflows, outbox patterns, idempotency, retries and dead-letter handling.
- ⚡ **Real-Time Systems** — WebSockets, real-time messaging, presence, location tracking and live updates.
- 💳 **Financial Systems** — wallets, transactions, ledgers, payments, fraud detection and transactional consistency.
- 📍 **Geospatial Systems** — location-based search, driver matching, property discovery and real-time location.
- 🎵 **Media & Streaming Systems** — audio streaming, playlists, media storage, CDN and high-volume delivery.
- 📰 **Social & Feed Systems** — feed generation, fan-out, ranking, caching and high-scale timelines.
- ☁️ **Cloud-Native Engineering** — Docker, cloud infrastructure, CI/CD, observability and production deployment.
- 🧩 **System Design** — scalability, resilience, security, consistency, caching and distributed-system patterns.
- 🤖 **AI-Powered Applications** — exploring practical ways to integrate AI into software products.
